# 旅行攻略 Skill 4.0

[English](README.en.md)

旅行杂志 4.0 将目的地介绍、每日行程和旅途工具放进一份可离线打开的 HTML。行前用来认识城市、比较餐厅和安排路线；旅途中切换旅行模式，查当天行程、找备选、记笔记和分摊费用。

延续大幅实景摄影与色彩叠印风格，同时照顾桌面阅读和手机上的快速查找。

## 主要功能

### 认识目的地，再开始旅行

城市介绍从地理、历史与当地生活展开，区域章节说明街区特色和可观察的细节。文化、餐饮与购物各有自己的内容，不把所有章节都写成每日行程的重复说明。

### 可以照着走，也留有余地的每日行程

每天包含停留顺序、建议时刻、游览时间、转场方式和用餐候选，搭配离线路线地图。遇到天气、休馆、预约或体力变化时，可查看当天备选，了解替换哪一段、怎么过去、需要重新确认什么。营业时间、店休和最后入场等限制纳入规划，日期未定时保留具体条件说明。

### 不只收录主线景点的地点库

地点库按目的地规模、地区特点和旅行天数规划，包含景点、文化场所、餐厅、咖啡馆及购物地点。支持搜索、区域筛选、收藏和详情查看，并提供地址、来源及导航入口。配图核对实际主体；没有可靠照片的地点保留完整文字卡。

### 餐饮与购物，帮助做具体选择

餐饮默认分为「值得专程吃」「当地特色」「日常连锁」「咖啡与甜品」，根据当地情况调整。展开后可查看推荐理由、怎么点、预算、分店位置和营业注意事项。

购物内容说明当地值得看的品类、用途、选择差异和具体去处；当天行程中的购买建议与实际地点对应。

### 手机上更顺手的旅行模式

日期导航、紧凑时间轴、交通和导航入口方便现场查看。「当天提醒与备选」合并折叠，餐厅候选和语言锦囊随时可查。切换工具时保留当天与阅读位置，不必反复返回杂志正文。

### 笔记、摄影参考与地点附件

按天记录旅途笔记，查看对应地点的摄影建议，也可以上传参考照片。票据与参考资料放在相关地点内，查地点时一起找到。上传图片支持完整查看，避免长图被强行裁切。

### 适合同伴旅行的记账工具

支持添加和管理成员、上传头像、录入及编辑账目、分摊费用和记录还款。不同币种分别统计，金额使用千位分隔，明细与结算可快速切换。内置可加载、可清除的演示数据，方便了解功能。

### 行前准备与场景语言锦囊

准备清单按「提前办理与预订」「临近出发核对」「出门前随身检查」组织，任务说明操作与完成条件，具体安排随目的地调整。

语言锦囊按点餐、交通、住宿、购物、参观、求助等场景整合会话、常用词和常见回答，支持大字出示与填写具体信息。非英语目的地保留当地语言和备用英语；英语目的地提供中文释义与一套英语，避免重复。

### 单文件离线使用与数据备份

照片、字体、地图和代码内嵌，无需启动服务即可打开。个人笔记、收藏、账目和附件支持备份与恢复。外部导航、预约网站和来源链接仍需联网；个人记录保存在当前浏览器中，跨设备使用时需导出、导入备份。

## 安装与升级

沿用原仓库和 Skill 名称：`build-personalized-travel-guide-open-source`。

1. 下载[最新安装包](https://github.com/TokenHungryMash/personalized-travel-guide-skill/releases/latest/download/personalized-travel-guide-open-source-skill.zip)，或下载本仓库默认分支的完整文件。
2. 将完整 Skill 文件夹放入宿主的技能目录；更新时替换原 Skill 文件夹，不另留一份同名旧版。个人工作台和浏览器数据另行保留。
3. 在 Codex 中说：`使用 $build-personalized-travel-guide-open-source 开始制作旅行手册。`
4. 确认安装目录的 `SKILL.md` 中 `metadata.version` 为 `4.0.0`。问卷之后先确认逐日行程，再制作完整杂志；明确要求直接生成时可跳过讨论。

固定在 `v3.0.0` 的下载链接仍指向历史版本；要更新请使用上面的 latest 安装包或默认分支。4.0 沿用安装入口，不自动改写既有 3.0 手册或浏览器记录。

需要 Python 3.10+ 及工作台 requirements.txt 中的依赖；浏览器验收需要 Node.js、Chromium 和相应依赖。生成过程需要联网检索及文件、图片和浏览器操作能力；生成的单文件可离线阅读。4.0 当前发行以离线杂志为交付，不包含 3.0 的 Cloudflare 部署工具或行程拖拽编辑。
