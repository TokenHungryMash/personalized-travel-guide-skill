# 视觉、配图与动效

## 已认可的设计语言

- 连续暖纸色正文、深黑文字、细分隔线。英文刊头与主标题使用 Outfit 的粗黑字重；中文长标题用 Noto Serif SC，正文用 Noto Sans SC。字体已附，新增内容要检查中文字形覆盖。
- 刊头保留醒目的横排 `PRIVATE JOURNAL`。城市大字随容器宽度缩放；窄屏不让一个英文单词挤成逐字竖排。天数、章节编号、具体时间作为稳定的阅读锚点。
- 桌面统一版心和左右边线，照片、图注、导语、按钮对齐；宽幅照片可以突破版心，但需要有内容目的。图文两列明确指定列位置，避免 CSS 的偶数项规则把照片和文字叠到同一格。
- 棕红、灰蓝、橄榄绿或琥珀色从相邻照片提取，用于叠字、日期、选中项与少量题头。避免给每章铺一整块不相干的饱和背景。

## 静态封面和摄影叠字

### 福冈色彩叠印：保留的版面基线

新版默认保留福冈色彩叠印与东京夜景的大图方向。需要还原具体样刊时，先实际打开其成品，分别查看封面、开篇、夜景与收尾摄影页。不能只读 CSS 或凭记忆把它解释为暖纸色加两栏卡片。

- 封面以占满可用首屏的大幅实景为主体，粗黑横排城市名直接叠在照片上，附中文城市名、天数与阅读入口。不要自行改成「纸面大标题＋独立小图＋侧栏介绍」。扣除实际导航高度，桌面和手机都应首屏看见阅读入口。
- 正文保留有节奏的整幅摄影页：整屏宽或接近版心宽的照片，上叠大字，之后衔接纸色攻略。不能将原有摄影大页全部收缩成等宽双卡或图文各半。地图、时间轴和工具仍以查询效率为先。
- 参考叠印语言包括奶油白实字、描边字、琥珀黄及浅绿；根据相邻照片选色，明亮背景可用深蓝。`screen`、`multiply` 等混合模式需要结合照片实看，避免所有图片蒙同一层灰黑再加白字。叠字必须与照片内容相符，白天观景图不能配「AFTER DARK」。
- 体验选题由整条路线和读者兴趣决定，不由碰巧找到的两张照片决定。抵达和返程之外的主要游览日，应能在区域章节找到对应的体验；可把体验与区域走法合并成摄影专题，避免一组任意精选卡片后又重复介绍同一街区。预约选项明确放回所属日期，不把可选项目包装成全程唯一重点。
- 验收实际图像：摄影主体、叠字可读性、全幅照片宽度、手机裁切，以及文字是否越界；增加素材数量或通过代码检查本身不代表恢复了福冈风格。

默认摄影封面，无视频控件、自动视频请求、视频降级提示或播放外跳。冻结福冈参考为中洲夜色，东京成品为新宿夜景；默认引擎的巴厘岛示例使用海岸摄影。新都市优先真实夜景，标题与按钮在扣除两层导航高度后的首屏内。其他城市根据照片主体选择封面，并按可用容器高度处理，不能沿用旧导航高度常量。

大幅摄影需要版面设计：短英文叠字、位置 / 章节标识，或与照片紧邻的导语。选明亮天空时用深字，夜景用浅字；必要时小范围渐变，避免整图压黑。字放在可用空域，不盖住建筑主体、人脸与关键地标，也不要为了塞文字把主体裁掉。用实看决定横排、分行、字号和颜色，不统一给所有图加同一种右上角标签。

桌面与手机分别指定照片比例、`object-position` 和叠字字号。参考版大濠用石桥与浮见堂构图，手机另调焦点，不沿用曾经导致空天空的长图和两倍放大。新图应重新判断这些参数；不得照抄具体百分比。

## 素材速度与准确性

先用现有经过核验的图库，其次查当地官方图库与可靠开放素材。每个需要补图的地点先看少量候选，通常 1–3 张；找到地点正确、裁切可用、清晰度足够的图就停止。失败后换来源或换布局，不反复验证同一张图。

- 大图源文件先满足最低像素：封面长边至少 2400、短边至少 1400，正文大图长边至少 1600、短边至少 900，横竖替代图分别检查。2000px 只是常见正文选图尺度，不代替封面门槛；小缩略图不要硬拉成全屏。详细检查及重复图片规则见 [大图质量门槛](release-verification.md#大图质量门槛)。
- 每个片区专题、餐饮大图和文化大图均实看主体并对照标题、路线与图注；跨区日按照片实际地点或准确主题说明关联，避免邻近区域图误配。修改 `foodPhoto` 时同时检查 `areas[].photo` 和对应图注，再构建截图。
- 不同正文大图位置使用不同图片与构图；当前构建会拒绝相同字节或近似指纹。同一位置的桌面／手机替代图可以是同一照片的不同裁切；同一地点在详情、时间轴、地点库中的识别图可以复用。不要为去重引入不准确配图。
- 不同地点不得共用同一张无关“城市氛围图”。没有准确识别图时用文字布局；附近区域图可独立用于区域专题并准确标注，不能放进具体场馆的识别卡冒充该场馆。品牌或菜品图按实际角色注明，不能伪造某餐厅、某酒店的实景。
- 保存来源页、作者、许可、拍摄地点、尺寸；必要时标注资料照片、拍摄年份与季节。版权署名放在可读图注，不塞进主体图片里。
- 不使用 AI 生成图冒充真实地点。是否另做概念图由用户需求决定，并明确标识。

## 导航与实用界面

导航层级是全书目录、当前大章节、章节内快捷入口和旅行模式。两套全书目录按实际章节顺序列出，每项有清楚中文用途；当前顺序见 [内容与功能](content-and-functions.md)。不重复放多个相似的旅行模式入口。章节跳转要留出固定导航高度。深色正文目录与浅色弹层目录分别设置文字颜色，说明小字相对实际背景至少 4.5:1，不能靠透明度做层次。

阅读栏采用两级导航：左侧显示当前大章节并打开全书目录；右侧随章节变化，承担当前章节内部的切换或跳转。每日行程显示实际旅行天数的日期按钮，并与正文及旅行模式共用选中日期；街区显示区域；餐饮显示分组；贴士显示主题，跳转时自动展开对应折叠项；准备章显示预约、清单和语言卡；地点库提供搜索、收藏及区域入口。不要在阅读所有章节时重复同一组全局快捷入口。选中态跟随实际滚动，日期按钮则跟随共享日期状态；窄屏保持横向可达并提示还有更多项目。复制小节链接、重新加载、键盘访问及打开旅行模式后返回原阅读位置，都需要验收。

攻略页的密度来自合理分组和消除重复：不要同时叠加很大的章节外边距、题头内边距、标题内边距和摘要下边距。日期已在固定栏与当天题头说明时，手机不再用独立大编号占据一列；时间、结束时间与停留点数可以紧凑排列，仍保留正常正文字号和明确点击区。以进入章节后能更早看到具体路线、地点或操作为验收依据，不靠缩小全文字号或删除摄影大页实现。

旅行模式沿用主刊字体、纸色、日期样式和边线。桌面可用时间轴加地图的两栏；手机为全屏单栏，日期与工具导航固定，地图可折叠，操作区触控高度约 44px。时间、地点、交通和导航优先，不把大图塞在当天第一条信息前。工具之间即时切换，不反复重演入场动画。

旅行模式采用较正文紧凑的密度：日期尽量单行，窄屏可横滑并自动露出当前选中日；压缩题头、条目间距和输入框初始高度，不能靠缩小正文或触控目标来挤内容。当天导语放入交通说明折叠项，主视图优先露出时间、地点、现场提示与导航。摄影、票据、笔记和账本同样收紧留白，长内容自然滚动；笔记框可扩展，手机输入字号保持至少 16px。

## 动效节奏

参考版的三处摄影动作分别为开篇图版展开、海湾轻微纵向位移、夜景两行文字反向归位。它们是设计示例，不要求每个城市必须原样做三次。需要按内容分配差异，普通标题、折叠内容和每条攻略不做通用滑入。

保持滚动与阅读自然；不劫持滚轮、不强制横向翻页。动效关闭与系统减少动态效果后，图片、文字、地图和功能都仍完整。只用必要的 transform / opacity，离屏不持续更新昂贵效果。
## 源图、压缩与显示尺寸

三个尺度分别判断：源图像素是清晰度最低门槛；离线压缩最长边默认封面 2560、正文 2000、地点 900，是控制交付体积的上限；正文桌面版心约 1800px 是布局上限。后两者不是源图最低值，也不意味着所有图都必须裁成同样比例。正文桌面默认约 1.65:1、手机约 4:5，再按主体调整；首屏封面按可用屏幕高度和主体裁切。降低 CSS 显示尺寸不会豁免仍被引用为大图的源文件门槛；小图应改作识别缩略图或移除大图用途，并同步数据与版式。

## 正文照片的独立裁切点

`edition-photos.json` 中每张正文图可填写 `position` 和 `mobilePosition`，格式为两个 0–100 范围的百分比，如 `"50% 0%"`。桌面与手机按各自焦点裁切；没填写时保留原版式。不要让银座钟楼、场馆正门等主体在宽屏裁切中丢失，也不把某城市的像素位置写死在公共 CSS 中。独立 `mobileSrc` 仍须满足原图质量要求；有尺寸不足的手机版本时应另选合格原图或使用主图配合裁切。
