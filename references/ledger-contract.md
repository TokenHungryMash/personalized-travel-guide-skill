# 旅行记账

参考原版手册的实用功能：账目可新增、修改、删除与撤销删除；记录项目、币种、金额、旅行日、可选实际日期、类别、付款人、分摊成员、支付方式和备注。提供日期／类别／付款人／币种筛选、CSV 导出、每人净额和已完成还款的登记／撤销。

不同币种分别汇总与结算，不把 JPY、CNY、USD 数字直接相加，也不把临时参考汇率写回账本。预算仅与同币种消费比较，界面说明其他币种未计入。当前参考换算是本期基础币种到 CNY，联网刷新需主动操作、失败保留手填值；它不改变账目、不执行支付，也不是任意目标币种或银行结算汇率服务。

算法先转换为币种的最小记账单位再均分，尾差按选中成员顺序分配；每笔分摊之和必须等于支付额，所有人净额之和为零。还款只改变债权债务，不增加消费。零小数币种与两位小数币种分别校验精度。

保持工作台已有存储键和备份格式。旧记录缺币种时按原版目的地币种解释，新增成员不自动分摊旧账。不得因新版本验证变更丢掉旧笔记、收藏、附件、消费或还款。新建手册初始预算来自 edition.json，不沿用参考目的地金额。账本是当前浏览器中的本地记录；同行成员只是分摊对象，不表示已经邀请对方、共享账单或同步到对方设备。

保留旧版的成员头像能力：在明确命名的「同行成员与头像」入口上传、更换或移除，分摊成员和结算双方同时显示头像；无图时回退姓名首字。当前本地引擎用可选 `memberAvatars` 字段补充既有成员姓名，不迁移账目引用。JPG / PNG / WebP 上传后居中裁成 128px JPEG，并限制保存大小；头像随本机状态和原备份格式导出、导入。旧备份缺头像字段仍有效。不能只保留头像占位样式而删除文件选择入口。实际测试上传、更换、移除、重载、备份往返，以及坏图和存储失败时保留原头像。

实际测试：一笔多人均分尾差、两种币种不混加、修改一笔后总额及结算变化、登记和撤销还款、筛选不改变总账、保存后刷新恢复、旧格式备份兼容。手机检查表单、长成员名与结算金额不溢出。

保存状态以实际持久化结果为准。新增／编辑消费、登记还款遇到本机写入失败时，可保留本页中的输入与记录，但必须在当前记账界面提示「尚未保存到本机，关闭前导出备份」，不能仍写「已保存」或仅把错误放在被弹层遮挡的外页。成员、头像和演示载入仍按各自契约失败回滚。用 `node scripts/check_ledger.cjs <工作台> --browser` 注入存储失败，核对新账、编辑和还款的提示、当前数据及原持久化数据。

## 演示案例

账本提供明确的「载入演示案例」入口，初始真实账本保持空白。`ledger-demo.js` 通过已有状态持久化：3 位参与者、5 笔虚构消费、基础币种与第二币种、一笔已完成还款，包含部分成员分摊、单人消费与均分尾差。金额仅用于功能展示，不作为当地价格事实。

不覆盖既有账目、成员、笔记或头像；重复点击不重复创建。演示记录用保留前缀 ID 标识，名称明确含演示；移除只处理这些记录与不再被其他账目引用、且确由本次演示加入的成员。新增成员名单写入可兼容的 notes 字符串字段，随备份保存；存储失败回滚，不让界面假装已保存。案例允许修改，仍能按保留 ID 单独移除。

内页提供记一笔、看明细、看结算的快捷定位；不能让定位目标被弹层工具栏挡住。测试载入、重复载入、重载、修改、移除和备份导出；先记一笔真实账目，移除案例后核对真实记录仍完整。

成员管理提供未引用成员删除及撤销；已被消费、还款或待撤销记录引用的成员仅移出新账分摊，保留历史结算，可恢复。停用名单保存在 notes.ledgerInactiveMembers JSON 字符串，旧备份兼容；至少保留一位当前成员。增删和恢复必须存储失败回滚。常用表单双列，补充日期、支付方式、备注折叠，演示案例位于表单之后。

金额显示使用千位逗号；预算、消费与还款输入在非编辑状态显示分组，聚焦时移除逗号方便编辑，允许粘贴合法分组金额。解析后才保存数字，币种精度与金额上下限照常校验，CSV与备份保留数值。
