- 技能名称：旅行杂志 4.0；标识 `build-personalized-travel-guide-open-source`；本地独立版。“4.0”是产品名称，当前发布版本以 `SKILL.md` 的 metadata 为准，避免维护多份版本号。
- 历史基线是 `TokenHungryMash/personalized-travel-guide-skill` 的 v3.0.0，本技能没有发布到该远端，也不替换其入口。
- 视觉与功能参考是经过用户逐轮确认的福冈四天三晚色彩叠印样刊。认可版 Git 保存点 `8919f5f`；本技能在其后移除了用户最新明确取消的封面视频，并沿用近期的旅行模式、导航、大濠换图、横排粗黑刊头、手机适配和动效修订。
- 12hrs、Monocle 与旅行杂志提供视觉参考；穷游锦囊提供内容结构启发。这里没有打包穷游 PDF、其全文、第三方整站或网站抓取副本。
