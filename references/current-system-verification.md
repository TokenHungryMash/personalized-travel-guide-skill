# Public scaffold verification

The public bundle is an empty component scaffold, not the former populated destination reference. Historical claims about 178 files, nine itinerary days, embedded maps and destination browser checks do not apply to this package.

Installation: expose the intake questionnaire. Host-required security review is separate. Do not run the full development suite or restore a destination snapshot as an installation prerequisite.

Maintenance: use audit_skill_consistency.py and the affected Python unittest cases. verify_handbook_system.py checks the actual bundled manifest after restoration; derive file counts from that manifest. The historical destination-specific test-system-browser.cjs is excluded from release ZIPs. test-system-routes.cjs now embeds a neutral synthetic raster and tests geometry without destination media; it does not validate geographic accuracy.

Generated handbook acceptance requires its real destination data and release-validation.md checks. A scaffold restore or a passing unit suite does not establish browser or WorkBuddy workflow success.
