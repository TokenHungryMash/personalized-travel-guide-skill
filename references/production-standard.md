# Production standard

This Skill has one production standard. There is no edition selector. Use complete canonical packs, truthful source observations, batch image inspection and representative desktop/mobile QA. Image dimensions are advisory; wrong subjects, invalid source records and broken files fail. See [production](production-flow.md), [image policy](image-and-source-policy.md), and [release validation](release-validation.md).

Persisted `quality_mode` is the fixed implementation value `standard`. It is not an intake option. Deeper testing follows the scope of a runtime change rather than a product tier.
