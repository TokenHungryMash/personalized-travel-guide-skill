# 新版问卷与确认流程

开始新旅程时，默认先交付可点击的离线问卷。用户明确说跳过问卷、直接制作，或已经确认本次逐日路线时继续相应阶段。用户已给目的地、天数或其他偏好时，预填到实际表单，用户只补自己想补的内容。聊天里已提供的信息不再询问，也不视为自动跳过问卷。

用 `python scripts/create_intake.py <输出HTML> --destination <目的地> --days <天数> --notes <其他说明>` 生成单文件问卷。仅传入已知字段。其他已知表单字段可通过 `--prefill <JSON文件>` 传入，字段名使用模板的表单 name。已知交通偏好填入其他说明。给用户生成文件的链接。目的地尚未确定时，保留空值并提供推荐模式入口。

用户可提交问卷生成的需求，也可在聊天中补充。之后给简短逐日草案，经确认再制作完整手册。问卷输出的 `routeApproved:false` 不代表路线已经确认。

问卷沿用原版的精简字段：目的地、出发／返回日期或天数、人数与同行关系、节奏、预算、兴趣、想去／避开的地方、限制与其他说明。不要再单独增加已订交通、已订住宿、步行习惯、地点库倾向、首次到访或住宿晚数；用户有需要可写入其他说明，未提供的预订保持待确认。不得要求认证凭据。不要根据目的地类型增加无关必填题。

问卷自身可离线打开，草稿保存在浏览器；复制失败时选中文字供手动复制，并提供 JSON 下载。校验真实日期、返回先后及日期与天数的冲突。保存失败必须提示，不能让生成按钮失效。目的地推荐模式先推荐候选，选定目的地仍需确认逐日草案。

## 与杂志统一的问卷版式

使用当前问卷成品，不回退旧版绿色圆角面板。保留 PRIVATE JOURNAL 大刊头、暖纸色、黑字细线、Outfit 标题、中文正文与衬线字体；所有字体内嵌。桌面用左侧章节索引与右侧表单，手机收成单栏。核心字段优先，兴趣、想去的地方与限制等选填内容折叠；表单按信息组安排，不能仅给旧问卷换色就称为完成改版。

章节导航、实时旅程摘要和选项状态需清楚。按钮、输入框、选项及错误提示使用同一套排印层级。实际查看 1440、390、320 宽度下的首屏、展开选填与生成结果，检查键盘焦点、长文字折行及点击区；保留原流程、草稿与输出格式兼容。

问卷不设置摄影、出片、拍摄设备、想拍什么或拍照氛围选项，生成文本与 JSON 也不自动附带摄影偏好。用户可自行在其他说明中补充；这项简化仅作用于问卷。

界面细节沿用当前成品：桌面为带轻微纸页层次的版心，手机铺满纸色；现有字段按行程时间、同行与节奏、旅行预算分组。目的地使用大字号下划线输入，其余表单保持细边框与一致的点击区；兴趣选中同时显示填色和标记。章节导航标示当前章节，生成入口使用深色纸面与浅色按钮。调整样式不得增加问卷字段，减少动态效果设置下关闭过渡。
